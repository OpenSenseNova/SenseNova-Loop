# Prompt

The original Chinese prompt is preserved below.

制作一个中文沉浸式叙事动态网页《奥德赛｜归乡漫游》

核心体验：用户通过滚动控制一条连续的镜头旅程，跟随奥德修斯从特洛伊启航，穿过洞穴、岛屿、冥界和风暴，最终回到伊萨卡。所有场景共用一个固定的全屏舞台，形成连贯的空间旅行。视觉风格：采用成熟动画电影质感的古希腊史诗插画

让动态成为页面的核心体验：停止滚动时，主体仍持续运动；滚动控制镜头穿行、物体形变和场景演化；鼠标能扰动局部画面。安排几次有冲击力的视觉变化，让前后场景通过同一个运动主体连续衔接。请实际实现这些动画，并让首屏打开就有明显动态。/canvas-design
