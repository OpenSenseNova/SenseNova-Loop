# Prompt

The original Chinese prompt is preserved below.

制作一套8页、16:9的教师节感谢PPT，由学生赠送给宋老师。

全部采用生图模式，每页都是完整高清画面。整体使用东方水墨雅致风，以宣纸、淡墨、灰蓝和克制暖金为主色，具有教师气质、文化内涵和高级感。

8页必须使用不同背景，分别表现：晨光讲台、粉笔黑板与飞鸟、批注作业与书页、秋雨校园长廊、山路引灯、夜晚教室暖灯、桃李花开、山高水长。每个场景都要与该页文案相呼应，但色彩、笔触、字体和版式保持统一,每一页ppt排版不重复。

封面写“致敬爱的宋老师”，末页写“宋老师，教师节快乐”，落款为“您的学生们”。

中文必须清晰准确，不出现错字、乱码、遮挡和裁切；内容可以适当扩展。文字区域与图片主题不遮挡.
