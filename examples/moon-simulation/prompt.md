# Prompt

The original Chinese prompt is preserved below.

请制作一个虚构月球任务「NOVA MISSION 07」的公开展示网站，融合太空任务叙事与可操作的控制中心。任务从地球出发，经历近地轨道、地月转移、绕月和着陆四个阶段。所有遥测使用明确标注的模拟数据。

首屏是一幅层次丰富的地月轨道场景：地球、月球、飞行器、轨迹、星场、坐标与关键读数共同构成主体。用 SVG/Canvas/轻量 WebGL 实现，地月尺寸和距离可为展示进行夸张，但在说明里写清。用户可播放/暂停任务、拖动时间轴、调整 1×/10×/100× 速度，并切换四个阶段；飞行器位置、任务说明、距离、速度、燃料、电量和通信延迟同步变化。轨迹是可解释的展示模型，各项读数变化连续且单位一致。

遥测区包含高度/速度曲线、子系统状态矩阵、通信事件流和可筛选告警。点击历史事件定位到对应时间，选中子系统后展示它的工作过程与一张关联曲线。提供可折叠任务简报与“导出当前任务快照”功能，快照包含当前时间、阶段和读数，支持下载 JSON。加入一次可恢复的模拟通信中断，让告警、事件和系统状态有真实的前后关联。

视觉采用深空海军蓝与荧光青，关键告警用琥珀色。主场景要有电影感，遥测面板有航天器仪表般的刻度、清楚的数字和层级；加入节制的扫描线、轨道辉光和微动效。页面信息密度高但要有清楚的视觉焦点，手机上保留任务场景和关键控制。

请交付可直接打开的 index.html 和所需本地资源，并完成实际浏览器检查。
